# Sewon Hur — academic website

A dependency-free static site designed for GitHub Pages and the custom domain `www.sewonhur.com`.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Push the contents of this directory to the root of a GitHub repository, enable GitHub Pages from the `main` branch, and keep the included `CNAME` file. DNS should only be changed after the GitHub Pages preview has been reviewed.

## Updating the CV

Replace `assets/Sewon-Hur-CV.pdf` with the new PDF, keeping the filename unchanged.
